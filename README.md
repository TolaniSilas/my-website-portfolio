# Silas Osunba's portfolio

Personal portfolio built with Next.js. News, Projects, Articles, and Books are managed through the private `/admin` dashboard and rendered on the server from Supabase. Articles link to Medium. Visitors do not need accounts; only the designated owner can manage content.

See [database and hosting setup](portfolio/supabase/README.md) before running the application. This app requires a Next.js server; GitHub Pages static hosting is not supported.

```sh
cd portfolio
npm ci
npm run dev
```
